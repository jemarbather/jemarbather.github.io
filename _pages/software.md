## twoPhaseSens

**Sensitivity Analysis for Covariates Observed in Two-Phase Samples**

Ojiambo R<sup>†</sup>, **Bather JR**. *twoPhaseSens*. R package version 0.1.0. 2026. [[CRAN](https://cran.stat.unipd.it/web/packages/twoPhaseSens/index.html)]

A structured workflow for sensitivity analysis in linear regression when key continuous covariates are measured only in a Phase-2 subsample. The package compares naive and complete-case analysis, multiple imputation (fully conditional specification and joint modeling), inverse probability weighting, and augmented inverse probability weighting, with standardized tables, diagnostics, and forest plots.

## biostats101

**Practical Functions for Biostatistics Beginners**

Mautner Wizentier M<sup>†</sup>, Goodman MS, **Bather JR**. *biostats101*. R package version 0.1.1. 2024. [[CRAN](https://cran.r-project.org/web/packages/biostats101/index.html)]

User-friendly functions that fill gaps in introductory biostatistics tools in R, so newcomers can run basic biostatistical analyses without advanced programming skills.
